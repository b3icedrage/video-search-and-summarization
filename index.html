One line in. A rendered animated clip out.

NIM Studio runs the whole storyboard-to-screen workflow on NVIDIA NIM endpoints: an LLM writes the structured storyboard, SDXL / FLUX.1 render consistent character stills, the audio layer writes SFX cues (plus optional TTS narration), and FFmpeg gives the stills camera motion and stitches them into a clip.

The architecture

Four layers, every endpoint swappable

Each layer is its own adapter with the model ID in configuration. Swap models by changing one environment variable — the same free nvapi-… key authenticates all of them.

1 Director Layer

Generates the structured JSON storyboard: shots, durations, camera moves, self-contained image prompts that repeat the style string for consistency, narration text, and per-shot SFX descriptions. JSON mode is requested and a fence-tolerant parser backs it up.

meta/llama-3.2-11b-vision-instruct openai/gpt-oss-20b · minimax-m3.1-flash

2 Visual Generation

One still per shot from the Director's prompts, on NVIDIA's image route (a different base URL than chat). The decoder accepts every known response shape — base64 artifacts, b64_json, or a URL — since the hosted schema isn't fully documented.

black-forest-labs/flux.1-dev meta/llama-3.2-11b-vision-instruct (director)

3 Audio / Voice

Written honestly: hosted audio models do speech and transcription, not squish sound effects. So this layer emits a timestamped SFX cue sheet (with a drop-in path per cue) and renders voiceover narration through Magpie TTS when requested.

magpie-tts-multilingual SFX = descriptions + file hooks

4 Animation Composite

Full video diffusion is skipped on purpose. Each still gets a camera move via zoompan, shots are cross-faded, and narration is trimmed and padded to the clip length. If ffmpeg is missing, a ready-to-run command script is written instead.

ffmpeg · libx264 · 1280×720 · 24fps

Quickstart

Run the full pipeline locally

The dry run works with no key at all — placeholder stills, a canned storyboard, and a real rendered clip. Add a key when you want live models.

~ / nim-studio
# 1. dependencies (ffmpeg on PATH for the composite)
pip install -r requirements.txt

# 2. offline dry-run — no key, still renders out/clip.mp4
python run_pipeline.py "a curious slime monster discovers a ramen shop"

# 3. live: get a free nvapi-… key at build.nvidia.com
export NVIDIA_API_KEY=nvapi-…
python run_pipeline.py "your idea" --live            # storyboard + stills
python run_pipeline.py "your idea" --live --narrate  # + TTS voiceover

# swap models without touching code
DIRECTOR_MODEL=meta/llama-3.1-70b-instruct \
IMAGE_MODEL=stabilityai/stable-diffusion-xl \
python run_pipeline.py "your idea" --live
